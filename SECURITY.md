# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately: on the repository page choose **Security**, then
**Report a vulnerability**. Do not open a public issue for a security problem.

This plugin runs with the permissions of the sparkrun user, launches containers, and mounts host
paths named in a recipe, so the reports that matter most concern recipe handling, the trust gate
for untrusted recipes, and the handling of the API key file path.

## Supported versions

Only the latest release is supported.
